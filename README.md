# BipalKattel Portfolio

BipalKattel Portfolio is a personal portfolio website designed to present my professional background, skills, experience, projects, and achievements in one place. It provides visitors with an overview of my work, interests, and capabilities through a clean, modern, and user-friendly design. The website is fully responsive and offers a smooth browsing experience across desktop, tablet, and mobile devices.

## Features

- Personal profile and About section
- Projects showcase
- Work experience and education
- Skills and achievements
- Photo gallery
- Contact form
- Responsive design for mobile and desktop
